# 显示模式与手势（更新至 0.1.34）

0.1.34 新增课表提醒：允许临时覆盖插件内黑屏或最小化画面，单击关闭或显示 20 秒后恢复原模式；不更改原来的恢复手势，不等同于退出息屏／最小化。具体条件见 [课表与提醒](timetable.md)。下表描述无提醒覆盖时的操作。

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| 标准首页 | 长按 | 进入黑屏待机 |
| 黑屏待机 | 新的长按 | 恢复标准首页 |
| 黑屏待机 | 单击、双击、滑动、应用菜单或手机操作 | 不恢复显示 |
| 标准首页 | 双击 | 最小化，仅显示日期和时间 |
| 最小化 | 双击 | 恢复标准首页 |
| 最小化 | 单击、长按、滑动、应用菜单或手机操作 | 不退出最小化 |

最小化保留原日期和时钟样式，不显示天气、电量、菜单或分隔线；仍按分钟更新。黑屏待机停止显示与天气定时刷新，保留不可见的手势接收容器；不是硬件断电。

一次长按只切换一次状态，必须松手再长按才能恢复，避免重复上报导致刚息屏就亮屏。标准首页的单击延迟 350ms 判定，确认不是双击后才打开栏目；双击、长按或滑动会取消待触发单击，滑动选项仍使用原来的快速路径。

普通详情页双击返回首页；Study 内的 Timetable、LeetCode daily 双击返回 Study，再双击返回主目录。主目录双击才进入 minimize。AI 页长按录音/松开发送、天气循环翻页等操作保持原逻辑。手机端不提供显示模式切换按钮；应用菜单只保留标准显示状态下的 Dashboard 返回入口，不能绕过息屏和最小化的恢复规则。系统层的菜单和退出入口仍由宿主管理。

运动传感器、10 秒自动最小化、头动恢复、校准及相关设置全部移除；本版不调用 imuControl。升级时移除旧的自动收起与校准偏好。事件分发只忽略宿主意外推送的 IMU 报告，避免被零值点击兼容逻辑误判为单击。
