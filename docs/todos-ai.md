# 待办与 AI 创建 · 0.1.33

## 眼镜操作

首页选择 **To-do list** 并单击进入。进入时仅显示未完成事项，上下滑动选择，左侧 `>` 标记当前选中项，底部显示截止日期与可选时间；列表超过五项时随选择滚动。单击完成当前项后，该项留在原位置，文字变暗并显示 `[x]`；再次单击可恢复亮度和 `[ ]`。完成项仍可选择、撤销，不会使后续项目自动补位。只有退出清单并重新进入时，才从眼镜上隐藏已完成事项。

单击等待 300ms 区分双击，双击会取消完成操作并返回主页，避免返回时意外完成一项。长按沿用详情页原有的 AI 语音操作。标题与事件捕获外框分离，选择不会导致原生标题滚动。

完成状态立即保存，手机清单保留完成项，可以恢复或删除。手机完成当前眼镜清单中的事项时，同样会留在眼镜上变暗；手机或 AI 新增未完成事项时追加到本次清单末尾。手机主动删除项目会立即移除该项。手机添加待办时可填写日期、时间；只填写日期不会默认补一个时间。日期已过的事项显示 Overdue。旧待办自动补为“无截止日期”，不会丢失原事项与完成状态。

## 手机界面

采用黑白灰、等宽字体与细线边框的 terminal 风格，顶栏可切换并保存深色／浅色。HUD、PLAN、AI、STUDY、Setup 五个固定标签切换主要功能，不再通过长主页上下寻找入口。PLAN 内包含 Tasks 与 Timetable 两个子标签，STUDY 包含 Daily、Algorithms 与 Teleprompt；设置内再用 AI、Voice、Search、Weather 四个小标签切换分类，底部保留保存按钮。

Tasks 用 Pending／Done 按钮筛选，每页最多五项，通过 Prev／Next 翻页；日期和时间折叠为可选区域。AI 输入栏、待办分页栏与设置保存按钮固定在各自页面底部，内容区可单独滚动。聊天记录、长题目与较长清单仍保留必要的内容滚动。

## AI 创建

直接在 AI assistant 用文字或语音说，例如：

> 帮我添加待办：2026年10月23日18:00前提交数学作业。

> 记一下，明天要带实验报告。

AI 使用现有聊天 Key 与模型。普通聊天走 Chat Completions function calling，OpenAI 内置搜索模式走 Responses function calling；Tavily 搜索继续与聊天接口一起使用。需要所选模型／兼容服务支持函数工具，未增加额外 API Key、外部待办服务或新的网络域名。具体协议见 [OpenAI 官方函数调用文档](https://developers.openai.com/api/docs/guides/function-calling)。

应用给模型提供手机本地日期、星期、时区以及最多二十条未完成事项，供解析相对日期和避免重复；这些内容会发送到用户配置的 AI 服务。日期表达存在歧义时，要求 AI 先追问，日期型截止事项保持为日期；未明确给出的时刻、科目不会自动补全。日期理解由所选模型完成，应用进一步校验真实日期和 HH:mm 格式。

工具每次最多创建五项，清单总容量为 100 项。应用校验完整批次，要求任务有来自近期用户消息的原文依据，不解析普通回复中的代码或 JSON 来直接写入。无效参数、截断的工具输出或写入失败会报错，不保留部分新项目。相同标题、截止日期与时间的未完成项不会重复添加；已完成项保留，允许另建新事项。

收到有效工具调用后，先写入插件的本地清单，再由应用根据实际保存的记录生成确认文本；不使用模型自行声称的“已保存”作为执行依据。此创建动作直接显示本地工具结果，不额外发起一次付费模型请求。工具模式的输出上限为 1024 tokens，保持原有模型与用户计费账号。

这是本插件自己的待办清单，不同步到 Even 系统自带待办服务，也不创建系统通知或定时响铃。日期和时间用于清单展示。

## 首页对齐

五个菜单标签都是相同 x 起点、独立 27px 高的单行原生文字容器，并与原图标行坐标对应。0.1.34 将 LeetCode daily 与新增 Timetable 收进 Study 子目录，主目录保持五行；子目录复用原文字槽位，未用行留空。分隔线和概要共享一个原生文字容器，保持主页在最多八个文字／四个图片容器的硬件上限内。所有选项文字亮度相同，保留原生 `<` / `-` 选择标记与菜单循环。

构建包含 TypeScript 检查；此版本没有使用用户的 API Key 发起真实模型请求，AI 创建与真机触控效果需安装后用自己的设置确认。
