# 离线算法库 · 0.1.36

## 入口与操作

眼镜：**Study → Algorithms**。主目录继续保持五行，Study 内为 Timetable、LeetCode daily、Algorithms、Teleprompt、Back。

算法目录始终最多显示五行，用 `>` 标记选中行、`+` 标记子文件夹；超过五项时窗口随选择移动，上下首尾循环。单击打开文件夹或笔记，双击返回上一级。根目录双击回到 Study，Study 双击回到主目录。

笔记使用原生文字和固定标题，每页七行；上下滑动移动两行，100ms 内同向连续事件合并，避免一次滑动跳过很多行。正文不做截图渲染，无需联网。返回时保留目录选中位置，当前插件运行期间保留每篇笔记的阅读位置；课表提醒结束后仍恢复原来的笔记与位置。

手机：**STUDY → Algorithms**。可浏览相同目录，搜索中文名、英文名、关键词和正文内容，用 Prev／Next 按钮分页。On glasses 可把当前目录或笔记直接打开到眼镜；处于息屏或 minimize 时，先通过原手势恢复显示。

当前版本内置 **104 篇**常用算法及数据结构笔记、**12 个大类**，另设二级分类。每篇包含适用场景、核心思路、时间／空间复杂度、语言无关的伪代码、易错点和具体例子。

笔记以中文讲解、英文算法名辅助检索。伪代码强调步骤，不是可直接复制运行的程序。复杂度按各条目所列实现与前提计算；数值基本运算按常数时间处理，涉及大整数时须再计入位数代价。期望、摊还和最坏复杂度分别注明。

例如：Dijkstra 要求非负边；普通滑动窗口不直接套到任意负数数组；0/1 与完全背包容量遍历方向不同；哈希不保证无碰撞；JS 普通位运算有 32 位限制；快速排序与 Quickselect 均保留最坏二次复杂度。资料没有在运行时交给 AI 生成。
